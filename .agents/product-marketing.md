# Dotnot — Product Context

Read this file before writing product copy. It describes the personal fork, not
an existing hosted service.

Last updated: 2026-11-17

## Product

Dotnot is an independent personal fork of a nested-outline editor. Its inherited
implementation includes daily notes, tasks, tags, links, mirrors, search, OPML
import/export, and optional authorized agent access over MCP.

There is no hosted Dotnot deployment, deployment domain, paid offering, support
address, founder profile, or verified customer testimonial configured for this
fork. Product copy must reflect that status.

## Intended value

Capture thoughts in a nested outline, find them later, and reorganize them with
keyboard commands. Show the actual editor and describe behavior supported by the
current implementation.

## Voice

Use calm, direct language. Keep paragraphs short and features concrete. State
what is available locally and what requires an operator to configure a service.

## Naming and links

- Human-visible product name: **Dotnot**.
- Repository: `unstppbl/dotnot`.
- Local app: `http://localhost:8787` through `bun run cf:dev`.
- `dotnot.example` and `app.dotnot.example` are reserved documentation examples.
- Lowercase package names, storage keys, CLI commands, and existing asset paths
  remain compatibility identifiers until changed deliberately.

## Open decisions

Deployment domain, public positioning, pricing, support arrangements, and launch
channels remain undecided. Inherited release notes and decision records are
technical history; they do not establish a running Dotnot service or promises
to customers.
