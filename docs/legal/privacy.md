# Dotnot Privacy Notice

Dotnot is currently a personal development fork. No public hosted service,
service operator contact, or deployment-specific privacy policy has been
configured.

When you run Dotnot locally, its development Worker and databases handle the
account and outline data you enter. Optional features can contact external
services, including link previews, embedded media, connected MCP clients, and
any providers you configure.

Before accepting other people's data in a deployment, its operator must publish
a privacy policy that describes the actual hosting, processors, access,
retention, deletion, and contact arrangements for that deployment.

The source code and inherited documentation do not establish those operational
practices for a future Dotnot service.
